# Tina — public site

Landing page and legal documents for the **Tina** iOS app, served via GitHub Pages.

- `index.html` — landing page
- `privacy.html` — Privacy Policy
- `terms.html` — Terms of Use
- `style.css` — shared styling (brand palette mirrors the app)

Live at: https://fdrc-tech.github.io/tina-site/

The legal text is kept in sync by hand with the in-app copy in
`LegalView.swift` of the (private) Tina app repo.
